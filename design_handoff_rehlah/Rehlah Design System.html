01

Principles

Four commitments the system enforces, so every screen agrees.

Grounded, not clinical

Warm sand neutrals and natural radii. No glossy gradients, no medical blue, no purple. The app should feel like a room, not a chart.

Journey before task

Every screen answers "where am I in my journey?" before "what's due?". Phase, cycle, and day-of-cycle are first-class data.

Bilingual, not translated

RTL is a starting condition, not an afterthought. Type, icons, motion direction and progress all mirror cleanly.

Quiet by default

Color is reserved for state, not decoration. Saffron means "today matters". Clay means "needs your attention". Sage means "you did it".

Touch-first density

44 pt minimum targets. Generous gaps. One primary action per screen — usually a check-in, sometimes a log.

Numbers earn their size

Adherence, temperature, days-to-next: numbers get hero treatment with tabular figures so they're scannable at arm's length.

Usage rules

A short list of "do this, not that" so the system doesn't drift as more screens get built.

Color rules

✓ Teal 700 for one primary action per screen.

✓ Saffron for "today" — FAB, milestone, next appointment.

✓ Sage / Clay reserved for state. Never decorative.

✗ No gradients except the HeroCard.

✗ No purple. Never. Anywhere.

Type rules

✓ One Newsreader moment per screen, max.

✓ Tabular numerals on all values, doses, times.

✓ Arabic numerals (٠١٢٣) for Arabic locale dates.

✗ Don't use Newsreader for buttons or labels.

Layout rules

✓ One HeroCard per screen, at the top.

✓ One primary button per screen.

✓ Phase banner above the fold on Home, Health, Care.

✗ Don't stack two coloured banners.
